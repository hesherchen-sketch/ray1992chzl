三、TOP 主题深度（推理三问）

① 羊字辈 / 生肖名字套利 —— 今天唯一有「龙头 + 梯队 + 三源人气」的方向

  • 大资金意图: 不是产业资金，是存量接力资金在找一个能过夜的容器。半导体 -147.83 亿、存储 -69.26 亿、PCB -59.54 亿、先进封装 -59.84 亿，科技硬件四条线合计流出超 330 亿；同日涨的板块是冰雪 +4.50 亿、供销社 +3.64 亿、红利破净 +3.44 亿、保险重仓 +6.67 亿 —— 钱在往「低位置 + 有名字 + 有辨识度」的地方躲。羊字辈的机制是：一个高度标杆（海洋王 8天7板）打出空间后，用「羊/洋/阳」把一批低价小票串成板块，对手盘是明日来接「第 2 个洋」「第 3 个羊」的接力盘。群F 把机制说得很直白：「羊字辈今天的主动性和板块效应都不错」「不会选票就海洋王，然后再猜一个弹性标」。
  • 为什么走强: 三源同时给票 —— ①涨停结构：6 家涨停（海洋王、襄阳轴承、光洋股份、阳光乳业、桂发祥、大洋电机），是当日唯一有「4 板 + 2 板×3 + 首板×2」完整梯队的方向；②人气榜：东财人气前 3 名全是羊字辈（襄阳轴承 3→1、海洋王 13→2、大洋电机 84→3，大洋电机 +81 是全场最大跃升），同花顺热股海洋王 5→1、襄阳 6→2；③封单质量：光洋股份 2 板封单 1.70 亿 / 成交 3.4 亿 = 50%，全场最厚且 0 开板。位置低是硬条件：光洋 88 亿、桂发祥 23 亿、阳光乳业 38 亿流通，都不需要机构定价，只需要辨识度。
