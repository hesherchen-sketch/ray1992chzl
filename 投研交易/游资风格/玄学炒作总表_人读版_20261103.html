A 股玄学炒作总表（人读版 · 各种情况）

用途：自己通读用的完整框架。玄学=最极致的情绪流炒作——谐音/拆字/联想是人的活，程序写不出；名字只是载体，赚钱效应才决定能不能追。
时间：2026-11-03 · 当前窗口=四季度跨年妖（2027 春节=羊年）
注意：历史案例是市场经典记忆（不是本系统回测），作联想锚用，不作统计证据。

零、总纲：先记住这三条

  1. 先认市场再认梗：没有情绪温度/赚钱效应，再好的名字梗也是自嗨。名字族多票涨停=扩散确认（可做）；高标断板/炸板=梗退潮（降级）；席位净卖=出货（划掉）。
  2. 梗会扩散，不预设死名单：字辈直炒 → 监管警告 → 切替身（谐音/拆字/同题材）。新梗追新不追旧。
  3. 纪律不破例：10cm 主板、市值≥20亿、打板/竞价确认、单票≤5%、炸板必卖、退潮不硬做。

二、字辈炒作

市场认”名字里的字”为辨识度，跟基本面无关。同字辈多票涨停=字辈行情启动。

字辈特征记忆
华字辈数量最多（179 只），辨识度弱化，需叠加题材华生科技、华升股份
圣字辈少而尖，易被点名圣阳股份、圣龙股份
宝字辈吉祥属性强宝塔实业、宝明科技
金字辈富贵联想，注意区分真黄金股四川金顶、金贵银业
龙字辈生肖+字辈双属性，跨年窗口最猛龙头股份、龙韵股份
如意/祥字辈直接吉祥寓意如意集团、老凤祥

识别：同字辈 3 只以上同时涨停/连板 → 字辈行情。跟随不纠正，不以”无逻辑”排除。

三、谐音炒作（最核心——字面规则全漏）

炒 A 字 → 读音相同的 B 字票被选中。名字不含目标字的票才是真实扩散方向。

主梗同音族（联想方向）实战锚
羊 yáng阳/洋/扬/杨/央/漾/养/秧阳光照明、东方海洋、扬子新材（全涨停）

识别：同音字票批量涨停（不是一只），且高标在同音族里 → 谐音扩散确认。

四、拆字炒作（最玄的一层）

炒某字 → 含该部件的字被联想。字面完全不含目标字。

目标部件含部件的字实战锚
羊群（君+羊）、祥/详（礻+羊）、美（羊+大）、善（羊+一+八）、鲜（鱼+羊）、羚（羊+令）、羲、羹利群股份（20261103 首板零开板）；祥源文旅、老凤祥、羚锐制药
龙龚、宠、庞、笼罕见，扩散弱
马驰、骏、腾、骅驰/骏/腾字票在窗口可联想
虎虑、虐、虚基本不扩散
凤风、凰、枫（谐音+部件混合）凤凰航运、凤凰股份

识别：含部件字票盘中突然点火（非题材驱动、无消息），多为当日发酵联想盘，首封时间晚=资金临时起意。

五、数字玄学

名字含吉祥数字，谐音吉利（八=发、九=久、六=顺、三=生）。

数字谐音记忆
三生三羊马（生肖+数字双命中）、三七互娱
六顺六国化工等
七起七匹狼（数字+狼双梗）、三七互娱
八发八方股份
九久九牧王、九阳股份、九安医疗（2021-22 大行情，数字+题材双驱动）
百/千/万/亿大数吉利百洋股份（百+洋双梗）、万向钱潮

识别：数字票+生肖/字辈/题材叠加时最易被点名；单数字无叠加则弱。

六、地名/地域炒作

一提地域就想到的票（心智锚）。政策/事件触发。

地域心智锚记忆
福建平潭发展用户钦定心智锚案例
上海上海九百、上海三毛上海本地股情绪
东方系东方海洋、东方材料、东方通信名字带东方=辨识度溢价
海南海南高速、海南椰岛自贸港政策
平潭/厦门平潭发展、厦门信达两岸/海西

识别：地域政策出台 + 该地名票涨停 → 地域行情。

七、代码玄学（小众）

股票代码尾号/谐音成梗。常与数字/生肖叠加，独立行情少。

识别：代码数字+名字梗双命中才值得看，单独代码梗不参与。

八、老妖复刻

情绪回暖时，历史妖股名字被再次联想（市场记忆）。

老妖当年逻辑复刻规律
东方通信2019 年 5G 大妖一提 5G/妖股就想到；成妖后是漫长下跌（养家警示）
九安医疗2021-22 检测大妖数字+题材双属性
中通客车2022 妖股人气老妖二波反包（陈小群打法）

识别：老妖票异动 + 龙虎榜净买 → 二波启动。反包二板是大资金舒适区（反包一板可能闷杀）；衰退期不做。

九、吉祥字炒作

名字带吉祥寓意，情绪载体。福/禄/寿/喜/吉/祥/瑞/安/泰/康/如意/发财。

记忆：老凤祥（祥）、祥源文旅、如意集团、梅雁吉祥、均瑶健康。
识别：吉祥字票+情绪主升期联动；情绪退潮即撤，无独立行情。

十、颜色炒作

金/银/紫/红/黑/黄。金银=富贵、红=吉利。

记忆：金贵银业、红太阳（红+阳双梗）、紫光股份、黑芝麻（黑字辈情绪票）。
识别：颜色+其他梗叠加优先；纯颜色弱。

十一、玄学动物炒作

龙/凤/麒麟/鹰/马/鹿/象。动物意象吉祥/霸气。

记忆：龙字辈、凤凰航运、麒麟信安、老鹰（无直接票，鹰字稀少）。
识别：动物字批量涨停+跨年窗口 = 活跃；只做有辨识度的核心，不做杂毛。

十二、产业联想炒作

题材热 → 名字像的票被联想（题材名与公司名共振）。

记忆：AI 行情→智能系/数科系；机器人行情→“人形”相关；芯片行情→“微/芯”系。
识别：题材爆发+名字匹配票涨停 = 产业联想；有主线时优先主线，妖股赛道并行。

十三、识别信号汇总（怎么判断”这个玄学题材在发酵”）

按优先级：

  1. 多票同族涨停：名字族今天 ≥3 只涨停 = 扩散确认（最重要）
  2. 高标反馈：同族最高连板几板？晋级/溢价如何？高标活着=还能追，断板=退潮
  3. 龙虎榜：同族票席位净买=资金真做；净卖=出货别接
  4. 监管信号：字辈被警告/特停 → 立刻找同音/同形/同题材替身（监管切换是扩散加速器）
  5. 情绪温度：涨停家数/炸板率/晋级率决定”能不能做”，不是”做什么”

十四、参与纪律（跨题材，妖股不破例）

项口径
板池10cm 主板（60.SH/00.SZ）；300/688（20cm）/920 排除
市值流通 <20 亿剔除（防庄股）；20-50 亿警惕不回避；≥50 亿最安全
换手健康 5-15%；死亡换手 >70% 排除；缩量一字连板=情绪股非妖
烂板多次开板/封单极薄 = 烂板陷阱，划掉
买点只打板/竞价确认（弱转强/卡位）；禁低吸（量小无承接=接飞刀）；禁追一字板；尾盘 14:30 后不打
仓位单票 ≤5% 轻仓试探；R6 霸榜出货 hard_reject 不豁免
退出炸板破均线必卖；席位转净卖离场；退潮不硬做；成妖后漫长下跌不恋战

十五、一页纸口诀（贴桌上）

  1. 名字族多票涨停 = 扩散确认，可做。
  2. 高标断板 = 梗退潮，降级。
  3. 席位净卖 = 出货，划掉。
  4. 新梗追新不追旧；监管警告后切替身。
  5. 玄学是极致情绪流——赚钱效应优先，名字只是载体。
  6. 10cm、≥20亿、打板/竞价、≤5%、炸板必卖，妖股不破例。
