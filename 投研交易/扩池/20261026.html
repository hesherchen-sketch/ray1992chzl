  • 商业模式/客户：机动车主动安全系统核心部件 + 铝合金精密压铸件。产品为电控/线控制动、电控空气悬架（ECAS）、以 AEBS 为代表的智能驾驶产品，覆盖商用车、乘用车、两轮车。2026 半年报 p12 自述：2014–2025 年气压电控制动中的 ABS 产销量连续十二年行业第一。[S1]
  • 增长：2022→2025 营收 13.26→23.93 亿元，三年 CAGR 21.76%；2026H1 营收 13.46 亿元、同比 +24.56%，扣非同比 +24.67%。
  • 质量/风险：2026H1 经营现金流仅 0.23 亿元，同比 −86.61%（公司归因“备货等经营性需求增加”），现金/合并净利润约 12%；毛利率 27.89%→28.29%，负债率 28.0%，流动比率 3.03，商誉/净资产 0.6%，账面无明显杠杆问题。真正的问题是增长有没有变成现金——这决定了它是不是“纸面成长”。[S1]
  • 股权/标签：瑞立集团持股 48.03%（20260630），为控股股东；半年报 p12 明确“被评定为国家级专精特新‘小巨人’企业、国家级制造业单项冠军示范企业”。这是上市主体口径的法定披露自述，仍不等于本次已核工信部有效复核名单。[S1]
  • 为何未入选：公募聚合 6.68%（476 条基金记录）虽是低读数，但份额映射未做；2022 基期未定位到原始年报页；现金转换未达健康线。三条任一未闭环，就不进正式名单。

观察B｜赛诺医疗（688108.SH）——增长最猛、标签最硬，估值也最贵

  • 商业模式/客户：高端介入医疗器械，覆盖心血管（冠脉支架/球囊）、脑血管（涂层密网支架等）、结构性心脏病三大领域，III 类器械注册制，国内 + 美日法子公司运营。[S2]
  • 增长：2022→2025 营收 1.93→5.25 亿元，三年 CAGR 39.67%；2026H1 营收 3.05 亿元、同比 +26.68%（冠脉 +20.71%、神经介入 +35.14%），扣非同比 +510.56%（低基数）。
  • 质量/风险：毛利率 63.64%→70.19%，负债率 21.0%，流动比率 2.66，经营现金流 0.94 亿元 > TTM 归母 0.84 亿元，现金转换反而是这批里最健康的。风险在估值与政策：PE(TTM) 69.6、PB 5.85；集采降价对神经介入球囊售价的压制已在半年报中体现（“销量大幅增长但售价大幅下降”）。[S2]
  • 股权/标签：最大股东天津伟信阳光 17.19%；半年报 p25 认定表明确列示“认定主体 工业和信息化部 / 国家级专精特新‘小巨人’企业 / 2024 年度 / 冠脉介入产品”。主体口径一手证据成立。[S2]
  • 为何未入选：17.19% 只是最大股东持股，实控人经济权益未穿透；PE 69.6 需要同业估值中位数才能判断贵不贵，本次未取得；公募聚合 4.73% 同样待份额映射。

观察C｜赛分科技（688758.SH）——国产替代逻辑最清楚，现金流转化最差

  • 商业模式/客户：色谱材料（分析色谱 + 工业纯化填料），客户是生物药/化药企业在分离纯化环节。半年报 p17–18 说明：制药企业产品获批时需报备色谱填料厂家，换供应商要走工艺开发、性能确认、寿命验证，客户黏性与转换成本高；公司自称关键性能已达到或超过 Cytiva、Merck 等进口竞品，逐步实现境内份额替代。[S3]
  • 增长：2022→2025 营收 2.13→4.03 亿元，三年 CAGR 23.72%；2026H1 营收 2.80 亿元、同比 +53.17%，归母 1.11 亿元、同比 +106.19%，扣非同比 +131.54%，规模效应显现。
  • 质量/风险：毛利率 70.6%→75.32%，负债率 11.8%，流动比率 6.81，无商誉；但经营现金流 0.86 亿元 / TTM 归母 1.84 亿元 ≈ 47%，利润没有同步变成现金（应收与存货占用需看附注）。PE(TTM) 50.9、PB 6.73，不便宜。[S3]
  • 股权/标签：最大股东黄学英 22.18%；半年报 p33 认定表列示“苏州赛分科技股份有限公司 / 国家级专精特新‘小巨人’企业 / 2024”，主体口径成立。[S3]
  • 为何未入选：现金转化 47% 低于 80% 健康参考；2025-01 上市，2022 年基期取自上市前披露，尚未定位原始页；公募聚合 8.68% 待映射。

观察D｜润本股份（603193.SH）——“被忽视”程度最高，但成长弹性最弱

  • 商业模式/客户：个人护理 + 驱蚊，三大系列（婴童护理、驱蚊、精油），线上直销（天猫/抖音/拼多多/快手）+ 平台经销代销。2026H1 累计专利 126 项，参与国家标准《洗涤用品安全技术规范》起草。[S4]
  • 增长：2022→2025 营收 8.56→15.45 亿元，三年 CAGR 21.74%；2026 前三季（公告 20261020）营收 14.06 亿元、同比 +13.63%，扣非同比 +15.87%——增速在候选里偏慢。
  • 质量/风险：负债率 4.96%，流动比率 14.10，有息负债/资产 0.01%，账上几乎无杠杆；毛利率 58.27%→60.63%；经营现金流 2.66 亿元 / TTM 归母 3.49 亿元 ≈ 76%，接近但未过 80%。风险是季节性（驱蚊夏季集中）与平台流量成本。[S4]
  • 股权/标签：广州卓凡投资控股持股 44.58%；公募聚合仅 1.77%（90 条），是这批里“最没被发现”的；半年报全文未检出“专精特新”，不贴标。[S4]
  • 为何未入选：增速刚刚过线且在下行；现金转化 76%；专精特新无证据；实控人未穿透。

观察E｜中微半导（688380.SH）——成长最顺，标签不能贴

  • 商业模式/客户：Fabless MCU 设计，产品含 MCU、ASIC（高精度模拟/电源管理/通信交互/功率驱动）、SoC、SPI NOR Flash；自有 IP 超 1000 个，工艺覆盖 40–180nm CMOS 等。[S5]
  • 增长：2022→2025 营收 6.37→11.22 亿元，三年 CAGR 20.79%；2026H1 营收 7.26 亿元、同比 +44.01%，归母 1.72 亿元、同比 +98.48%，扣非 +109.74%，公司归因 AI/机器人/汽车电子景气与大客户战略。
  • 质量/风险：毛利率 33.25%→38.75%，负债率 14.84%，流动比率 6.17，无商誉；经营现金流 1.93 亿元 / TTM 归母 3.69 亿元 ≈ 52%，存货与应收账款是主要占用。PE(TTM) 36.9、PB 4.22。
  • 股权/标签：最大股东杨勇 31.47%；公募聚合 2.31%（264 条），低持仓。专精特新：半年报检出的“国家专精特新小巨人”指的是其参股的珠海博雅，不是上市主体本身——因此本期不给主体贴标。[S5]
  • 为何未入选：现金转化 52%；主体标签未核；控制人未穿透。
