3.3 分数跨期不可比的量化（缺口第 45 条的续）

本期池子换了成分（峰岹出、天振进），分位基数变了，所以今天的分不能直接减昨天的公布分。用同一版代码、同一批财务与筹码、只把价格从 11/20 收盘换到 11/23 收盘做内循环（stage_drift）：价格效应区间只有 −0.17 ~ +0.62 分（离散跳格：估值一格 0.62、筹码一格 0.46、流动性一格 0.17）。而公布分对比：天德钰 69.68 → 71.35（+1.67）、路维 67.07 → 68.46（+1.39）、四川黄金 64.22 → 65.32（+1.10）、赛诺 67.39 → 68.32（+0.93）、兴齐 67.11 → 68.04（+0.93）、百龙 66.59 → 67.06（+0.47）、广信 66.06 → 66.06（0.00）。用 29 只（剔天振）重算基数，天德钰是 70.33——即加入天振一只就抬了 1.02 分。所以 +1.67 里绝大部分是基座变动，不是价格，也不是基本面。跨期读分必须先把”公布值 / 回算值 / 不同基座值”分开。
