# 催化剂

本目录由 SkillHub 集成产生。

## 维护节奏

- **每周一 07:30** 由 cron `8588cd3d9943` 生成 `YYYYMMDD.md`（取当周周一日期），前视窗口 4 周。
- 单文件结构：frontmatter（date / horizon / 覆盖范围 / data_sources）→ 核心结论 → 覆盖范围 → 关键事件时间表 → 本周重点 → 下周预览 → 远期展望 → 位置含义 → 归档 → 数据来源与维护节奏。

## 数据来源口径

| 类型 | 来源 | 说明 |
|---|---|---|
| 中国官方数据发布日 | `cn_schedule`（stats.gov.cn） | PMI / CPI / PPI / 经济数据 / 工业经济效益，逐月有官方定档 |
| 海外数据与央行事件 | `eco_cal`（tushare） | 含 预期值 / 前值 / 实际值，可回填 |
| 财报披露日 | `disclosure_date`（tushare） | `actual_date` 为实际披露日，`pre_date` 为预约日 |
| 限售解禁 | `share_float`（tushare） | **必须逐票查**，按日期区间查会被 6000 行上限截断 |
| 当日市场定性 | R1 / R2 / R4 artifact | 覆盖范围由当日主线决定，不跨日沿用 |

## 补录纪律

补录文件只写两类内容：**当时可预期的日历**（官方定档 + 预约披露日）与**已兑现的实际值**（eco_cal 回填）。不虚构当时的盘中判断，不复述当时的仓位决策。事件实际值缺失时留空，不用预期值冒充。
