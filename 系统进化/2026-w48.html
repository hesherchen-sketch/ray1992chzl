二、成功经验（5 条）

  1. 11-26 的「条件-买区一致性自检」是本周唯一一条「改完就生效」的逻辑修正。 当日三条 entry_rules 全部写了自检并标注无互斥项 —— 而 11-25 中际的 (c)「不破 T-1 低点 415.21」与买区 [403,410] 结构性互斥，导致该腿在任何行情下都不可成交。一条自检，值一条腿。
  2. 11-25 长川科技的行业红盘率闸门第一次真正救钱。 半导体红盘率全天实测 0.07~0.21（远低于 0.6 门槛）→ 三条闸门全灭 → 挡住当日 −9.88%（收盘）/ −6.18%（开→收）的亏损腿。闸门用板块宽度而不是个股强度，这是本周最值钱的可复制经验。
  3. 11-26 的 R6 怀疑「R2 打分虚高 + 资金前提」两条全中。 医药链 70 分被证伪（涨停 13→1、红盘率 11.5%）、「钱撤出科技硬件」被推翻（CPO +64.67 亿 / PCB +44.12 亿回流）。证明 R6 本身不是废的 —— 它废的只是「质量红旗 → 次日涨跌」这一跳。
  4. 守正出奇轨的 falsifier 条件本周 4/4 命中（北方华创跌破 MA50 / 半导体红盘率 <0.5 / 沪电跌破 MA5 / 印制电路板资金腿）。证伪条件写得准，是本周逻辑层最准的部分。
  5. 11-26 用户签的三档改造（entry_slots）诊断精准。 病根定位到「买区机械设在昨收/均价下方 → 单边上涨日结构性零成交」，证据是三连 0 成交 + 11-27 中际买区上沿 430.15 vs 最低 430.69 差 0.54 元。诊断完全正确 —— 但代码没接线，见下文失败教训第 1 条。

三、失败教训（5 条）

  1. ⚠️ 最严重：三档改造已签、代码已写，但从未执行过一次。
    data/evolution/2026-W48/sign_off_log.md 记录用户 11-27 盘后已签核 entry_slots 三档；src/plan/price_levels.py:240-246 确实生成了三档；d1_algorithm.py:930-934 的 gap_open_confirm 通道也带三档。
    但实测：data/plans/ 全库 entry_slots 命中 0 次、gap_open_confirm 命中 0 次。 11-27 的 4 条 entry_rules 全部没有 entry_slots 字段。根因：apply_price_levels.py 不在任何 cron/pipeline 链路上（enforce_position_policy.py:11 写明「D1 明确按指令不跑 apply_price_levels」）。
    → 一段没有接线的代码，等于没有这个功能。而它的账单是 11-27 的 +19.98% / +20.00% / +15.08%。
  2. R6 把「质量红旗」直接翻译成看空方向，连续 4 个交易日全错（0/9）。
    九阳 +10.01%（龙虎榜净买 +3.22 亿全场第一）、凡拓 +16.64%、中京 +9.98% → +10.00%（5 板）、浙文 +10.14%、克来 +10.00%（5 板）。
    同期「弱势/断板/孤军」型看空 8/9 全对（华虹 −13.89% / 石药 −7.90% / 源杰 −4.72% / 工业富联 −3.30%）。
    → R6 今天的判断力是「看空弱势票很准、看空强势票全错」。这不是随机错，是有方向的错 —— 而 60% 的总兑现率把这个偏差完全盖住了。
  3. R2 打分 → D1 仓位，中间没有「当日宽度」这道闸。
    11-26 D1 把 4%（最大权重）给了白酒Ⅲ，理由是「10 日 +15.67 亿」—— 用累计资金当当期承接证据。当日白酒红盘率 5.3%、中位 −1.44%、0 涨停，是执行池唯一负收益腿；而红盘率 59.3%、3 涨停的百货拿到 0 仓位，红盘率 50.0%、3 涨停的造纸只拿 3% 且被 P1 封门（踏空 +12.43%）。
    → 把 R2 的软偏差放大成了 4% 的硬仓位。
  4. 滚动账本的假仓问题连续 3 日复发，且本周新发现跨日口径自相矛盾。
    引擎建仓不看 far_above / P1 skip / plan_status，买区外按开盘价虚拟成交 —— 本周 5 条假仓（源杰 680 建仓、青山 3.83 建仓等）。
    更严重的是：11-25 记为假仓的「中际 401.0 / 新易盛 175.1 / 深南 199.48（plan_date=20261125）」，11-26 又把完全相同的三条记为真实持仓（+7.28 / +7.96 / +2.50）。同一条腿在相邻两日的 E1 里既是假仓又是真仓 → 11-26 已实现胜率 0.2、均值 −5.52% 的分母不可信。
  5. 闸门设计三类缺陷同周复发：止损落在日内噪声区（沪电差 0.04 元被扫）、条款与买区结构性互斥（中际 11-25）、板块资金阈值当二元开关（青山 −0.13 亿判死一条 +10.05% 的腿）。
    → 闸门不是越严越好，是要「在正确的量级上严格」。用噪声量级当否决权，比没有闸门更糟。
