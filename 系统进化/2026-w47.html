三个必须说清的口径问题：

  1. 预判命中率不可计算。 SOUL 铁律 #1 要求 E1 每天落 prediction_review（命中/证伪/归因）。全库实测：含该字段的 artifact 只有 12 份，全部在 7 月和 10-22；本周 4/4 天全缺，连续缺失已 12 天。本周命中率 = 无分母，不是 0%。
  2. 观察池兑现率也不可计算。 expected_direction 在 5 份 plan 里覆盖 0/21、0/24、0/20、0/21、0/21 → expected_met_rate 本周 4/4 天为 null。这已是该契约缺口的第 8 次复发。
  3. 纪律违反扫描本周 0 天落盘。 含 discipline_scan 的 artifact 全库只有 1 份（10-22）。16 份错题里 0 份带 violation_code —— SOUL 要求的 5 字段格式，violation_code/ts_code/name 16/16 全缺。

成功经验（3-5 条）

  1. R6 反证层是本周唯一稳定有效的风控。 兑现率 0.722，11-19 单日 0.900；11-18 直接避免九阳股份（−9.99% 跌停）与阳光照明（−10.00% 跌停）两条腿，11-19 避免泰嘉 −9.98%、协创 −7.84%、阳光照明 −9.94%、文投 −9.90%。问题不在 R6 判得准不准，在 D1 消费不消费它 —— 11-19 R6 明写「默认执行池必须为空」，D1 仍给满 4 腿。
  2. 守正出奇轨的证伪质量本周满分。 11-17 4/4、11-18 3/3、11-19 3/3。11-18 判「影视院线 0 家封死 / 游戏 0 家封死 / 两条跌停」三条全中，这是本周最值钱的一次判断（D1 同日执行池 −2.53%，而守正轨空仓）。它不靠选股赚钱，靠”该放弃的先放弃”赚。
  3. 拦截机制净效果为正，不能整体放松。 11-19 拦截池 11 只 open→close 等权 +3.06%，显著高于执行池 +0.01%。它救下 4 只 −7.8% ~ −10.0% 的大跌，同时误杀 3 只涨停。问题只在”昨日龙虎榜净卖”这一条单条理由 100% 误杀（真视通 +10.02% 一字 3 板 / 卡莱特 +19.97% 收全天最高 / 九阳地天板 +10.01%，三只全部 MCP 逐只复核），不是拦截层本身有问题。
  4. “诚实的空仓”被做出来了。 11-18 三腿买区 100% 触及仍 0 成交、11-19 四腿 0 成交，E1 没有把”零成交”写成”亏损”，也没有把纸面涨幅写成收益。这是复盘诚实度的底线，本周守住了。
  5. 错题本的记账纪律本身是有效的。 16 份错题全部带 wrong_logic / market_feedback / corrected_logic / confidence 四段结构，且明确标出 correction_not_applied —— 正因为它诚实标出了”这条没执行”，本周才数得出 14/16 这个数字。否则本周会看起来比实际好得多。

失败教训（3-5 条）

  1. 上游的定量结论落不到仓位上（本周第一大问题）。

    • 11-19：R2 自己写 stage=climax + holding_days_max=0 + “次日腰斩概率 66%“，D1 仍给常山北明 8%、润泽科技 8%。当日算力租赁涨停 22→4 家，润泽 −8.65%。
    • 11-17：R2 给 70 分「擦线主线」、R6 对该链出 5 条 strong_suggest，D1 仍给 2 腿，其中慈文传媒是传媒链第 3 顺位（直接违反 leader_preference）。当日传媒链 4 龙头 3 只跌停，这两腿贡献 −1.72pp。
    • 归因：决策层，不是研究层。 研究层写对了，下一层没读。

  2. P1 只校竞价，不校 R6、不校身位、不逐腿覆盖。

    • 11-17：P1 当日放行的 3 条里，唯一被放行的那条恰好是唯一亏的（吉视 −8.91% 买点口径），被 defer 的慈文避免了 −6.28%。

  3. 闸门用错尺子：4 条腿共用一把全市场广度。 11-19 G1/G2 双 FAIL → 拦下润泽 −7.87%，同时拦下北方华创 +3.99% 与深南 +5.00%（MCP 逐只复核）。净效果仅 +0.11pp —— 不是亏钱，是把赚的和亏的一起扔掉。设备/制造是当日唯一资金连续加码方向（设备 +18.55 亿 / 5 日 +56.83 亿），算力租赁 −23.25 亿，两条腿的证据完全相反，却共用同一阈值。
